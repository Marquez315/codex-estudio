Guía de uso para principiantes

Una recorrida rápida por lo esencial. Tocá cada título para abrirlo.

¿Qué es Codex Studio?

Es un editor de código que corre en el navegador, pensado para escribir, guardar y previsualizar proyectos web (HTML, CSS, JS y más) sin instalar programas pesados. Podés usarlo con un repositorio de GitHub o de forma local, sin conexión a internet.

1. Empezar un proyecto

Sin GitHub: tocá "Nuevo proyecto local" y empezá a crear archivos ya mismo.

Con GitHub: escribí usuario/repositorio en el campo de arriba y tocá "Cargar repo". Para repos privados o para publicar cambios, cargá tu token en Ajustes (⚙).

2. Crear y organizar archivos

En el panel EXPLORADOR (ícono de archivo en la barra lateral), usá los íconos de arriba para crear un archivo nuevo o una carpeta nueva. Pasá el mouse (o mantené tocado en celular) sobre un archivo para renombrarlo o eliminarlo.

3. Ver el resultado (Vista previa)

Con un archivo HTML abierto, tocá "👁 Vista previa" arriba del editor para ver cómo se ve tu página en tiempo real, en una ventana al lado (o debajo, en celular).

4. Pedir ayuda al Asistente de IA

Abrí el panel de IA (ícono de globo/chat) y cargá tu API key gratis de Groq en Ajustes (⚙). Después escribí qué necesitás sobre el archivo abierto: que lo explique, corrija un error o genere una función.

5. Guardar y publicar cambios

Si estás trabajando sobre un repositorio de GitHub, el botón "Guardar y publicar" sube tus cambios como un commit real. Necesitás tu token de GitHub cargado en Ajustes. En un proyecto local, los cambios se guardan solos en el navegador.

6. Trabajar sin conexión (offline)

La app guarda en tu navegador el último proyecto que usaste, así que podés seguir editando sin internet. Los cambios pendientes se marcan y se publican solos apenas vuelva la conexión. El puntito de arriba a la derecha indica si estás en línea o no.

7. Instalar la app (celular o computadora)

Instalarla te da un ícono propio y la posibilidad de abrirla como una app, incluso sin conexión.

Android (Chrome): tocá el botón ⇩ de arriba: se abre el instalador nativo del navegador. Si no aparece, probá el menú ⋮ → "Instalar aplicación".

Computadora (Chrome / Edge): tocá el botón ⇩ de arriba, o el ícono de instalar que aparece en la barra de direcciones.

iPhone / iPad (Safari): Safari no tiene instalador automático, es siempre manual: tocá el botón compartir (el cuadradito con la flecha hacia arriba) → "Agregar a pantalla de inicio".

¿El botón ⇩ no instala nada? Asegurate de estar abriendo la app desde una dirección http:// o https:// (por ejemplo, ya publicada en GitHub Pages), no con doble clic sobre el archivo (file://): por seguridad, ningún navegador permite instalar ni trabajar offline así. Además, una vez instalada, el botón ya no vuelve a ofrecer instalar de nuevo en ese mismo dispositivo.

8. Consejos para trabajar desde el celular

El texto del editor ajusta el renglón automáticamente para no tener que desplazar hacia los costados. Usá el ícono de archivo (📄) o de IA arriba a la izquierda para abrir el panel lateral, y tocá afuera del panel para cerrarlo. Girar el celular en horizontal te da más espacio para programar cómodamente.
